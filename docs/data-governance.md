# Gobernanza de datos

Estados: `official` (fuente primaria y ración exacta) o `estimate` (rango editorial). Campos obligatorios: id, nombre, categoría, kcal, rango si varía, ración, estado, fuente, URL, mercado y fecha. IDs son estables y no se reutilizan. España y otros mercados nunca se mezclan. Revisión: oficial anual o ante cambio; estimación semestral. Toda alta requiere fuente, segunda revisión y `npm run validate`.
